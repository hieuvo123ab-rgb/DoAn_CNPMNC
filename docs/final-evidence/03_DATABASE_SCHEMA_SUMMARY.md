## 2. Detailed Schema Definitions

### 2.1 Table `users`
- **Purpose**: Lưu trữ danh tính người dùng và quyền hạn truy cập hệ thống.
- **Columns**:
  - `id`: `BIGINT`, GENERATED BY DEFAULT AS IDENTITY, **PRIMARY KEY**.
  - `username`: `VARCHAR(50)`, NOT NULL, **UNIQUE**.
  - `password`: `VARCHAR(255)`, NOT NULL (Mã hóa một chiều chuẩn BCrypt, không bao giờ lưu plaintext).
  - `full_name`: `VARCHAR(100)`.
  - `email`: `VARCHAR(100)`.
  - `role`: `VARCHAR(20)`, NOT NULL, CHECK constraint `role IN ('ROLE_USER', 'ROLE_STAFF', 'ROLE_ADMIN')`.
  - `enabled`: `BOOLEAN`, NOT NULL, DEFAULT `true`.
  - `created_at`: `TIMESTAMPTZ(6)`, NOT NULL.
- **Indexes**:
  - `users_pkey`: PRIMARY KEY (`id`).
  - `ukr43af9ap4edm43mmtq01oddj6`: UNIQUE (`username`).

### 2.2 Table `documents`
- **Purpose**: Quản lý hồ sơ tài liệu điện tử và siêu dữ liệu (metadata).
- **Columns**:
  - `id`: `BIGINT`, GENERATED BY DEFAULT AS IDENTITY, **PRIMARY KEY**.
  - `title`: `VARCHAR(255)`, NOT NULL (Tiêu đề tài liệu).
  - `description`: `VARCHAR(1000)` (Mô tả nội dung tóm tắt).
  - `document_type`: `VARCHAR(50)` (Phân loại văn bản: Báo cáo, Hợp đồng, Công văn, Quyết định, v.v.).
  - `content_type`: `VARCHAR(100)` (MIME type tệp, ví dụ `application/pdf`, `text/plain`).
  - `file_size`: `BIGINT`, NOT NULL (Kích thước tệp tính theo bytes).
  - `original_file_name`: `VARCHAR(255)`, NOT NULL (Tên tệp gốc khi tải lên).
  - `stored_file_name`: `VARCHAR(255)`, NOT NULL (Tên tệp lưu trữ vật lý duy nhất với tiền tố UUID trên đĩa).
  - `created_by`: `VARCHAR(50)`, NOT NULL (Tên người dùng đã tải lên tài liệu).
  - `created_at`: `TIMESTAMPTZ(6)`, NOT NULL (Thời điểm khởi tạo).
  - `updated_at`: `TIMESTAMPTZ(6)`, NOT NULL (Thời điểm cập nhật metadata gần nhất).
- **Indexes**:
  - `documents_pkey`: PRIMARY KEY (`id`).

### 2.3 Table `saved_searches`
- **Purpose**: Lưu trữ điều kiện tìm kiếm và phân loại của người dùng hiện tại (US-07).
- **Columns**:
  - `id`: `BIGINT`, GENERATED BY DEFAULT AS IDENTITY, **PRIMARY KEY**.
  - `name`: `VARCHAR(100)`, NOT NULL (Tên bộ lọc người dùng đặt).
  - `search_query`: `VARCHAR(255)` (Từ khóa tìm kiếm).
  - `document_type`: `VARCHAR(50)` (Thể loại được lọc).
  - `created_by`: `VARCHAR(50)`, NOT NULL (Tên người dùng sở hữu bộ lọc, đảm bảo nguyên tắc cô lập dữ liệu).
  - `created_at`: `TIMESTAMPTZ(6)`, NOT NULL.
- **Indexes**:
  - `saved_searches_pkey`: PRIMARY KEY (`id`).

### 2.4 Table `audit_logs`
- **Purpose**: Lưu trữ các vết kiểm toán (Audit Trail) của toàn bộ hệ thống (US-18, US-19, US-20).
- **Columns**:
  - `id`: `BIGINT`, GENERATED BY DEFAULT AS IDENTITY, **PRIMARY KEY**.
  - `username`: `VARCHAR(255)`, NOT NULL (Người thực hiện hành động).
  - `action`: `VARCHAR(255)`, NOT NULL (Mã sự kiện: `DOCUMENT_UPLOAD`, `LOGIN_SUCCESS`, `USER_ROLE_CHANGE`, v.v.).
  - `resource_type`: `VARCHAR(255)` (`DOCUMENT`, `USER`, `AUTH`, `SAVED_SEARCH`).
  - `resource_id`: `VARCHAR(255)` (ID thực thể liên quan).
  - `description`: `VARCHAR(1000)` (Mô tả chi tiết hành động dễ hiểu cho quản trị viên).
  - `ip_address`: `VARCHAR(255)` (Địa chỉ IP máy trạm phát sinh yêu cầu).
  - `timestamp`: `TIMESTAMPTZ(6)`, NOT NULL (Thời điểm phát sinh hành động chính xác).
- **Indexes**:
  - `audit_logs_pkey`: PRIMARY KEY (`id`).
  - `idx_audit_action`: BTREE (`action`).
  - `idx_audit_timestamp`: BTREE (`timestamp`).
  - `idx_audit_username`: BTREE (`username`).

## 3. Physical Storage Coupling

- **Physical File Path**: `/app/storage/uploads` bên trong container backend (`edms-backend`), được ánh xạ qua Docker volume `edms_storage_data`.
- **Integrity**: Mỗi bản ghi trong bảng `documents` liên kết 1:1 với một tệp tin vật lý thông qua trường `stored_file_name`. Hiện tại toàn bộ 49 tài liệu đều có tệp vật lý tương ứng nguyên vẹn trên đĩa.

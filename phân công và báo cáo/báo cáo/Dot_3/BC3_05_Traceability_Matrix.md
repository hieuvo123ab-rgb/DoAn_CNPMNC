## 1. NGUYÊN TẮC CẬP NHẬT MA TRẬN TRUY VẾT ĐỢT 3

Ma trận truy vết yêu cầu (Requirements Traceability Matrix - RTM v2) được nâng cấp từ phiên bản Đợt 2 nhằm ghi nhận những bước tiến vượt bậc về củng cố an ninh và thương mại hóa giao diện:
$$\text{Requirement (Yêu cầu)} \longrightarrow \text{Frontend Screen (Giao diện sạch)} \longrightarrow \text{REST API (Đã khóa)} \longrightarrow \text{Backend Service} \longrightarrow \text{Database Table} \longleftrightarrow \text{UML Diagram}$$

### Quy ước trạng thái Đợt 3:
- **`VERIFIED_ALIGNED`**: Yêu cầu nghiệp vụ cốt lõi đã được kiểm định chéo hoàn chỉnh, giao diện người dùng sạch bóng nhãn đồ án, API và Service vận hành ổn định trên 456 bài kiểm thử baseline.
- **`HARDENED_ALIGNED`**: Phân hệ mở rộng đã được củng cố bảo mật chuyên sâu (Profile guard, JWT 256-bit secret check, non-root user, X.509 RSA-2048, disaster recovery).
- **`OWNER-OPEN`**: Các điểm mở đang triển khai theo lộ trình của Project Lead (như tối ưu WebSocket Push ở Đợt 4).
